# 選舉人生：福爾摩沙

> 從二〇二六年的一個沒沒無聞的人開始，在一個每一項數字都會回頭咬你的台灣，走到權力的頂端——或者摔下去。

單機網頁文字模擬遊戲。原生 JavaScript，零執行期依賴，零建置步驟，`git push` 就能部署到 GitHub Pages。

## 玩法

從**政治素人**或**議員助理**開始，一路選到總統。每個回合是一個月，選前兩個月自動變成一週一回合。你有 **2 點行動點**，要在跑攤、上節目、研擬法案、募款、拜會派系、陪家人之間取捨。

這個世界不會等你。二十二個縣市、一百九十五個議員選區、五千八百五十群人各自有自己的日子要過，十五個世界區塊也在自己的軌道上運行。你不做事，它們照樣會變。

## 幾個設計上的堅持

**抽象數值一律用四個字。** 你不會看到「氣魄 3.7」，你看到的是「敢作敢當」。人口、金錢、得票率這種具體的東西才用數字。這不只是包裝——0～5 的粒度逼著設計者回答「這一級跟下一級到底差在哪」，也讓玩家沒辦法靠微調數字最佳化，只能靠判斷。

**汙名印象只增不減。** 清廉印象是輿論，可以靠時間跟形象工程拉回來；汙名印象是紀錄，媒體跟對手永遠可以再翻出來。收了附帶條件的錢、挪用了競選經費、拿不實的資料上質詢台——每一次都會留下痕跡。走清白路線要付出真實的資源代價，走汙名路線要付出真實的長期代價，兩條路都能贏，但贏的方式不一樣。

**氣魄決定你看得到哪些選項。** 不只是加值。氣魄低的角色在事件裡看不到「跟黨中央攤牌」這種選項；氣魄高的角色會失去「先低調觀望」——太衝的人做不出退縮的樣子，做了會被自己的支持者笑。

**支持度跟出門投票是兩件事。** 每群人除了支持哪一黨，還有一個「熱情度」。熱情低的支持者仍然支持你，但投票日不會出門。這就是催票跟造勢真正在做的事。

**基層組織是選舉真正的護城河。** 每個選區、每個政黨、還有你自己，各有一個 0～5 的基層組織值。從零長到「組織綿密」大概要四十個月的持續跑攤。民調領先但基層是零的候選人，會在開票那天發現支持者根本沒出門。

**得票公式最後乘一個 0.98～1.05。** 不對稱是刻意的：政治的意外通常是爆冷，不是爆穩。在複數選區，這個數字會讓配票精算的人有落馬風險——這正是真實選舉的樣子。

**種子。** 開局輸入一組種子，這個世界的所有政治人物、初始擾動、事件序列、重大轉折的年份、每一場選舉的隨機數就固定下來了。同一組種子重開，世界一模一樣，不一樣的只有你的選擇。

## 執行

**最簡單的方式**：打開 `dist/選舉人生.html`，直接雙擊就能玩。那是把所有程式與資料內嵌在一起的單檔版本。

**開發時**：

```bash
# Windows
start.bat

# macOS / Linux
./start.sh

# 或自己開
python3 -m http.server 8080     # 然後打開 http://localhost:8080
```

**為什麼不能直接用 `file://` 開 `index.html`**：瀏覽器基於安全考量，禁止 `file://` 頁面用 ES Modules 與 `fetch` 載入本機檔案，程式根本不會執行。多檔版本必須透過 HTTP 服務。單檔版本沒有這個限制，因為它不需要載入任何外部檔案。

改完程式碼之後要重新產生單檔版：

```bash
node tools/build-single.js
```

## 開發

```bash
node tools/validate-data.js        # 資料檔完整性（CI 會擋）
node tests/load.mjs                # 所有模組可載入
node tests/render.mjs              # 所有頁面可渲染、存讀檔往返一致
node tests/election.mjs            # 選舉系統
node tests/headless.mjs SEED 120   # 無介面跑 120 回合，檢查數值不失控
```

### 目錄

```
data/       所有平衡數值。改這裡不需要動程式碼
src/core/   Rng（種子亂數）、GameState、TurnEngine、Modifier、Expr（事件條件求值器）
src/systems/17 個系統，每個都是 tick(state, ctx)，不碰 DOM
src/ui/     頁面與元件，只讀 state，透過 dispatch 改變
docs/       策劃書與項目計畫
```

三條鐵則：UI 不直接寫入 state；系統層不碰 DOM；所有隨機都走 `Rng`（帶 seed），存檔才能重現、bug 才能複製。

### 寫事件的規矩

`data/events/*.json`。硬性規範，`validate-data.js` 會檢查：

1. **非特殊情況下，句子不得少於 7 個字。** 唯一例外是引號內的人物對白。短句堆疊是機器寫作最明顯的痕跡。
2. 標題 14～26 字，內文每句 20 字以上，要有具體的人事時地物。
3. **每則至少 3 個選項，且沒有明顯最優解**——每個選項的代價必須落在不同維度上。
4. 不得出現真實人名、政黨名、企業名、媒體名。
5. 不做立場宣導，同一議題的正反方都要有站得住腳的論述。

## 部署

Settings → Pages → 從 `main` 分支的根目錄部署。所有資源都用相對路徑，`.nojekyll` 已經放好了。發布新版時記得改 `sw.js` 裡的快取版本號，否則玩家會卡在舊版。
