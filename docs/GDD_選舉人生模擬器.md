## 1. 遊戲概述


### 1.1 一句話定位

> 從 2026 年的政治素人開始，在一個每一項數字都會回頭咬你的台灣，走到權力的頂端——或者摔下去。

### 1.2 核心體驗支柱

| 支柱 | 說明 |
|---|---|
| **世界是活的** | 22 個縣市與中央各自有人口、經濟、建設、文化、產業與股市數值，即使玩家不做任何事，它們也會依模型演化。玩家看到的每個新聞都由數值變化生成，不是罐頭文本。 |
| **人是有立場的** | 選民不是一個支持率數字，而是分佈在各縣市、各職業、各世代的 POP 群體，各有利益與意識形態，會因為你的法案而受益或受害，並用選票回報你。 |
| **權力是有代價的** | 每一次通過法案、砍預算、上質詢台、跟派系交易，都會在別的地方留下帳。短期民調與長期國家體質經常互相矛盾。 |
| **選擇是可讀的** | 純文字介面，但每個選項都會預告「這會影響什麼」的方向（不給精確數字），讓玩家能推理而不是亂猜。 |

### 1.3 目標玩家

- 玩過《Democracy》《Suzerain》《President Simulator》但覺得台灣情境沒人做的玩家
- 玩過《Victoria 3》《Europa Universalis》，喜歡看 POP 與價值觀滑桿慢慢移動的模擬愛好者
- 對台灣政治熟悉、會想測試「如果換我來做會怎樣」的本地玩家

### 1.4 單局長度

- 一屆任期（4 年 = 48 回合）：約 3–5 小時
- 完整生涯（2026 → 2050，最多 288 回合）：約 20–30 小時
- 支援任意回合存檔、快速結算模式（跳過細節事件）

### 1.5 明確不做的事（範圍護欄）

- 不做即時戰鬥、不做 3D、不做多人連線
- 不做真實人物的模擬或影射性攻擊
- 不做立場宣導：所有意識形態路線都必須有可行的勝利路徑與真實的代價

## 3. 數值呈現規範：四字語詞刻度

### 3.1 核心原則

本遊戲的數值分成兩類，呈現方式截然不同：

| 類別 | 範例 | 呈現 |
|---|---|---|
| **具體量** | 人口、金錢、GDP、席次、得票率、投票率、稅率、電價、失業率、通膨、民調百分比 | **一律用精確數字**，該是 2,470,368 人就寫 2,470,368 人 |
| **抽象量** | 能力、好感、態度、組織、士氣、印象、傾向、熱度、水準 | **一律設計成 0~5 或 −5~+5 的整數**，UI 上以**四字語詞**呈現，不顯示數字 |

抽象量在引擎內部允許小數（便於累積），但**任何顯示給玩家的地方都四捨五入取整並轉為語詞**。

### 3.2 為什麼這樣做

1. 「氣魄 3.7」對玩家沒有意義，「敢作敢當」有畫面
2. 0~5 的粒度逼迫設計者思考「這一級跟下一級的差別是什麼」，避免用小數字掩飾平衡問題
3. 抽象量刻度粗，玩家無法用微調數字的方式最佳化，只能靠判斷
4. 文字遊戲的質感來自用詞，不來自數字

### 3.3 刻度型別

```js
// src/util/scale.js
export const SCALES = {
  stamina:   { range: [0,5],  words: ["形銷骨立","弱不禁風","勉力支撐","精力充沛","龍精虎猛","鐵打之身"] },
  favor:     { range: [-5,5], words: ["恨之入骨","深惡痛絕","嗤之以鼻","頗有微詞","略有保留","漠不關心",
                                       "尚可接受","樂觀其成","心悅誠服","死心塌地","奉若神明"] },
  // …完整表見附錄 B
};

export function toWord(scaleId, value) {
  const s = SCALES[scaleId];
  const i = Math.round(clamp(value, s.range[0], s.range[1])) - s.range[0];
  return s.words[i];
}
```

**軸向型刻度**（價值觀、政治光譜等有方向的量）用另一種組合式呈現：

```js
export const AXIS_SCALES = {
  unification: { neg: "本土認同", pos: "傾向統合" }
};
export const INTENSITY = ["勢均力敵","微弱傾向","略有傾向","明顯偏向","主流共識","舉國一致"];
// 值 −4 → "本土認同・主流共識"
```

### 3.4 變動的呈現

數值變動也用語詞，不用數字：

| 變動量（抽象量） | 呈現 |
|---|---|
| ≥ +2 | 「大幅好轉」（綠色雙箭頭） |
| +1 | 「有所改善」（綠色箭頭） |
| 0（但內部有累積） | 「略有鬆動」（灰色點） |
| −1 | 「有所惡化」（紅色箭頭） |
| ≤ −2 | 「急遽惡化」（紅色雙箭頭） |

具體量的變動則顯示精確差值與百分比。

## 4. 核心循環與時間系統

### 4.1 雙尺度時間

| 模式 | 觸發條件 | 一回合 | 說明 |
|---|---|---|---|
| **月回合** | 平時 | 1 個月 | 預設節奏，經濟與 POP 完整結算 |
| **週回合** | 距離任何一場玩家參與的選舉 **2 個月以內** | 1 週 | 選戰模式，共 8～9 個週回合 |

**開局**：2026 年 1 月（第 1 回合）
**上限**：2050 年 12 月，或角色死亡／退休

週回合期間，所有連續性系統（經濟、POP、價值觀、世界）以 **1/4 強度**結算，事件抽樣頻率提高至 1.6 倍，競選專屬行動解鎖。選舉開票的那一週結束後，時間回到月回合。

```js
// TurnEngine 判斷
function scaleForTurn(state) {
  const d = monthsUntilPlayerElection(state);
  return (d !== null && d <= 2) ? 'week' : 'month';
}
```

### 4.3 回合內流程

```
[回合開始] ─ 判定 month / week 尺度
  ↓
① 世界結算（15 區塊演化 → 對台外部衝擊）
  ↓
② 經濟結算（22 縣市 + 中央；企業 mood 與股市）
  ↓
③ POP 結算（生活水準 → 意識形態漂移 → 政黨支持度 → 激進度）
  ↓
④ 國家價值觀漂移（8 軸，月回合最多 ±0.02 級）
  ↓
⑤ 政治結算（派系好感、基層組織自然衰退、政黨團結度）
  ↓
⑥ 玩家結算（薪俸入帳、團隊薪資支出、獻金到期、疲勞恢復）
  ↓
⑦ 過勞檢定（見 §5.6）→ 若住院則跳過 ⑧⑨
  ↓
⑧ 事件生成（依數值閾值 + 種子亂數抽出 1–4 則）
  ↓
⑨ 【玩家行動階段】2 AP
  ↓
⑩ 議程階段（會期：法案與質詢｜預算期：審查｜選戰期：競選行動）
  ↓
⑪ 媒體結算（新聞頭條、議題熱度衰減、民調更新）
  ↓
[回合結束 → 自動存檔]
```

### 4.4 委任幕僚模式

玩家可開啟「委任幕僚」：低優先度事件由團隊依玩家設定的意識形態自動處理，只回報結果摘要。委任處理的事件效果打七折，且有小機率讓幕僚做出玩家不樂見的決定。用於長期無選舉的平淡期。

**各屬性的作用**

| 屬性 | 主要影響 |
|---|---|
| 體力 | 疲勞恢復速度、住院機率、年齡衰退的緩衝、可執行的高強度行動 |
| 交際 | 派系好感獲取效率、幕僚招募與忠誠、跨黨協商、獻金募集 |
| 魅力 | 選舉的個人因素權重、造勢場效果、媒體鏡頭表現、選民第一印象 |
| 口才 | 質詢與辯論檢定、演講、記者會的框架設定能力 |
| 判斷 | 事件選項的隱藏資訊揭露、法案效果預覽精度、避開陷阱、識破爆料真偽 |
| 氣魄 | 高風險行動的成功率與可用性、對抗中央或黨中央、危機時的鎮定加成 |

**氣魄的特殊設計**：氣魄不只是加值，它**決定哪些選項會出現**。氣魄 0～1 的角色在事件中看不到「跟黨中央攤牌」「拒絕大老請託」這類選項；氣魄 4～5 的角色則會失去「低調處理」「先觀望」這類選項——太衝的人做不出退縮的樣子，做了會被媒體與支持者嘲笑。

| 全國知名度 | 抽象 | 0～5 | 無人知曉 / 略有耳聞 / 小有名氣 / 廣為人知 / 家喻戶曉 / 舉國皆知 |
| 全國好感度 | 抽象 | −5～5 | favor 刻度 |
| 選區好感度 | 抽象 | 每選區 −5～5 | favor 刻度，195 個選區各一 |
| 清廉印象 | 抽象 | 0～5 | 聲名狼藉 / 屢遭質疑 / 尚有爭議 / 大致清白 / 操守可信 / 兩袖清風 |
| **汙名印象** | 抽象 | 0～5 | **只增不減**，見 §5.5 |

| 疲勞 | 抽象 | 0～5 | 神清氣爽 / 略感疲憊 / 睡眠不足 / 心力交瘁 / 油盡燈枯 / 病倒在即 |

| 年齡 | 具體 | 歲 | 影響體力恢復與部分事件 |

### 5.5 汙名印象（只增不減）

這是本遊戲最殘酷的設計，也是它的道德重量所在。

- **範圍 0～5，只會上升，任何手段都無法降低**
- 語詞：`0 清白之身｜1 微有瑕疵｜2 物議紛紛｜3 惡評如潮｜4 聲名狼藉｜5 萬夫所指`

**與「清廉印象」的差別**：清廉印象是**流動的輿論**，可以靠形象工程、時間、危機處理拉回來；汙名印象是**留在檔案裡的事實**，媒體與對手永遠可以翻出來。

**累積來源**（每次觸發 +0.2～+1.0）

| 行為 | 增量 |
|---|---|
| 接受附帶條件的企業獻金 | +0.2 |
| 接受地下金流 | +1.0 |
| 挪用競選經費入私帳 | +0.8 |
| 財產申報不實被揭發 | +0.6 |
| 質詢時使用不實爆料 | +0.5 |
| 為自保切割下屬 | +0.4 |
| 承諾跳票被證實 | +0.3 |
| 貪瀆案不起訴（仍留紀錄） | +0.7 |
| 貪瀆案起訴 | +1.5 |

**效果**（依當前級數）

| 級數 | 效果 |
|---|---|
| 1 | 對手在選戰中可用此攻擊，−1% 得票 |
| 2 | 中間選民與學生 POP 好感 −1；記者會有機率被追問 |
| 3 | 黨內提名時派系需額外 favor；−4% 得票；調查事件機率 +50% |
| 4 | 部分幕僚拒絕加入；跨黨協商成功率 −25%；−8% 得票 |
| 5 | 無法出任內閣或黨主席；結局評價自動封頂為「有汙點的政客」類型 |

**設計意圖**：讓玩家在「這次拿了會方便很多」與「這筆帳會跟我一輩子」之間做真正困難的選擇。走清白路線要付出真實的資源代價，走汙名路線要付出真實的長期代價，兩條路都能贏，但贏的方式不同。

### 5.6 行動點與過勞住院機制

**行動點 AP = 2**（基礎），加成：

| 來源 | AP |
|---|---|
| 基礎 | 2 |
| 職位（縣市長 / 部會首長 / 總統） | +1 |
| 團隊有競選經理且處於選戰期 | +1 |
| 體力屬性 = 5 | +1 |
| 疲勞 ≥ 4 | −1 |

**沒有硬性體力條**。取而代之的是隱藏的疲勞累積與住院檢定。

```
每回合：
  fatigueRaw += Σ(本回合行動的疲勞成本)          // 一般行動 8，高強度行動 15，休息 −20
  fatigueRaw -= (10 + 體力 × 4 − 年齡懲罰)        // 年齡懲罰：55+ 為 4，65+ 為 8，75+ 為 14
  fatigueRaw = clamp(fatigueRaw, 0, 120)

  住院機率 P = max(0, (fatigueRaw − 45) / 150) × (1 + (5 − 體力) × 0.18)
              × (1 + 年齡係數)
```

**住院結果**
- 跳過 1～3 回合（依 fatigueRaw 決定），期間所有行動由團隊代理
- 全國好感 +1（同情效應），但議程完全停擺，法案與質詢機會流失
- 對手趁機推進自己的議程
- fatigueRaw 歸零
- **20% 機率體力屬性永久 −1**（這是不可逆的損耗）
- 若住院時體力屬性已為 0 → 觸發「健康崩潰」結局分支

**設計意圖**：玩家不會盯著一條血條精算，而是會有「我這幾個月是不是操過頭了」的模糊焦慮——這比血條真實。UI 只用四字語詞提示疲勞程度，且在「心力交瘁」以上才會主動跳出關心提示。

## 6. 玩家財務系統

三個帳戶，彼此隔離，混用要付代價。

### 6.1 私有財產（personalAssets）

**具體數值，單位新台幣。**

| 收入 | 金額 |
|---|---|
| 議員月薪 | 約 12 萬 |
| 立委月薪 | 約 19 萬 |
| 縣市長月薪 | 約 24 萬 |
| 部會首長月薪 | 約 22 萬 |
| 總統月薪 | 約 47 萬 |
| 投資收益 | 私產 × 股市指數變動 × 投資比例（玩家可設定 0～60%） |
| 演講與出書 | 知名度 ≥3 時每回合 3～30 萬 |
| 家族事業分紅 | 依背景 |

| 支出 | 金額 |
|---|---|
| 生活開支 | 每月 5～25 萬（依職位形象需求，職位越高越花錢） |
| 家庭事件 | 子女學費、父母醫療、婚喪，單筆 10～500 萬 |
| 選舉自付額 | 保證金 + 競選經費不足時的墊付 |
| 訴訟費用 | 單案 50～800 萬 |

**破產機制**：私產 < 0 且持續 3 回合 → 觸發債務事件鏈，強制變賣、被金主趁虛而入（汙名風險），或宣告退出政壇。

### 6.2 競選經費（campaignFunds）

**專戶。可以從私產轉入，不能從專戶轉入私產（轉了就是挪用）。**

| 收入 | 說明 |
|---|---|
| 政治獻金 | 見 §6.3 |
| 政黨補助 | 依黨內聲望與提名層級，選舉期每回合撥款 |
| 選舉補助款 | 得票數 × 30 元，選後一次入帳，未達門檻不給 |
| 私產轉入 | 隨時可，無代價 |

| 支出 | 說明 |
|---|---|
| 團隊薪資 | 每回合固定支出，見 §7 |
| 競選行動 | 廣告、造勢、文宣、網路投放 |
| 服務處維持 | 每個經營中的選區每回合 3～15 萬 |
| 基層組織維護 | 基層組織每高一級，每回合維護費倍增 |

### 6.3 政治獻金

每回合可能出現 0～3 筆獻金提案，玩家逐筆決定收或不收。

```js
{
  id: "DON_20260304_1",
  source: "corporate",           // small | corporate | faction | shadow
  donorName: "臺原石化",
  amount: 8000000,
  condition: {                   // 附帶條件，可為 null
    type: "lawStance",
    target: "LAW_CARBON_FEE",
    expect: "oppose",
    deadline: 24
  },
  stigmaOnAccept: 0.2,
  investigationRisk: 0.08,
  expiresIn: 2
}
```

| 來源 | 金額級距 | 條件 | 汙名 | 取得門檻 |
|---|---|---|---|---|
| **小額群眾** | 5 萬～120 萬 | 無 | 0 | 全國好感 ≥2 且網路聲量高 |
| **企業獻金** | 300 萬～3000 萬 | 政策期待（法案立場、標案、環評） | +0.2 | 企業 mood ≥3 |
| **派系金脈** | 200 萬～1500 萬 | 人事推薦或提名承諾 | +0.1 | 派系好感 ≥3 |
| **地下金流** | 2000 萬～1.5 億 | 表面無條件，實則綁定 | +1.0 | 汙名 ≥1 才會有人來找 |

**違約反噬**：接受了附帶條件的獻金卻在期限內做出相反決定 → 該金主 mood 暴跌、資訊外流事件、汙名 +0.5、可能被提告。這讓「收錢再翻臉」不是免費的聰明策略。

**申報系統**：每年 12 月財產申報。系統比對申報值與實際私產：
- 差額 < 5% → 無事
- 差額 5%～20% → 媒體質疑事件
- 差額 > 20% → 汙名 +0.6，調查事件機率大增

### 6.4 財務的 UI 呈現

三個帳戶並列顯示精確金額，下方一行趨勢：「本月淨額 −38 萬」。獻金提案以卡片呈現，卡片上明白寫出附帶條件與汙名風險（用語詞，不用機率數字）：

> **臺原石化 政治獻金 800 萬元**
> 對方希望你在碳費法案上站在產業這邊。
> ⚠ 收下這筆錢會留下紀錄，往後翻不掉。

## 7. 玩家團隊系統

### 7.1 職位槽

團隊槽位隨玩家職位解鎖：

| 玩家職位 | 槽位數 |
|---|---|
| 素人 / 助理 | 1 |
| 里長 / 議員 | 2 |
| 立委 | 4 |
| 縣市長 / 部會首長 | 5 |
| 總統 | 6 |

| 職位 | 主要效果 |
|---|---|
| **競選經理** | 選戰期 AP +1；競選行動效果依其能力提升 |
| **政策幕僚** | 法案品質 +；質詢準備效果加倍；事件選項揭露更多資訊 |
| **發言人** | 媒體框架控制 +；危機事件傷害減免；記者會效果 + |
| **組織部長** | 基層組織成長速度 +；服務處維持費 − |
| **財務長** | 獻金上限 +；獻金的汙名風險 −；申報差額自動修正 |
| **法律顧問** | 調查事件抵抗 +；選舉訴訟；契約與獻金合規審查 |

### 7.2 幕僚資料結構

```js
{
  id: "npc_00812",
  name: "林俊霖",
  role: "policy",             // manager | policy | spokesperson | organizer | finance | legal
  ability: 3,                 // 0-5，四字語詞：庸碌無為/勉可任事/稱職本分/獨當一面/幹練老練/國士無雙
  loyalty: 3,                 // 0-5：暗藏異心/貌合神離/公事公辦/忠心耿耿/生死與共/肝膽相照
  ambition: 4,                // 0-5：野心，高者會要求回報，也可能自立門戶
  salary: 90000,              // 每月，由競選經費支付
  specialty: ["財政", "能源"],
  knownSecrets: 2             // 知道玩家多少見不得光的事
}
```

### 7.3 招募與流失

**招募**：每回合有機率出現求職者卡片，或玩家花 1 AP 主動獵才。可招募到的幕僚品質取決於：玩家知名度、黨內聲望、交際屬性、開出的薪水、**汙名印象（高汙名會嚇跑好人才）**。

**培養**：花 1 AP 培養，能力或忠誠 +1（能力上限受幕僚天賦限制）。

**流失與背叛**

| 情境 | 結果 |
|---|---|
| 薪水拖欠 2 回合 | 忠誠 −1 |
| 忠誠 ≤ 1 且被對手挖角 | 離職，帶走部分選區組織 |
| 忠誠 = 0 且 knownSecrets ≥ 2 | **背叛爆料**：汙名 +0.8、進入醜聞事件鏈 |
| ambition ≥ 4 且玩家長期不給機會 | 自立門戶參選，成為同選區對手 |
| 玩家為自保切割幕僚 | 該幕僚離職且成為爆料者；其他幕僚忠誠 −1 |

**設計意圖**：團隊不只是加值面板，是一組會記仇的人。玩家做過的每件髒事都至少有一個幕僚知道。

## 8. 開局起點與種子系統

### 8.1 起點（2 種）

| 起點 | 難度 | 開局年齡 | 初始資源 | 目標曲線 |
|---|---|---|---|---|
| **政治素人** | ★★★★★ | 26–32 | 私產依背景、競選經費 0、知名度 0、無黨籍或剛入黨、家鄉選區基層組織 1 | 里長 → 議員 → 立委 → 縣市長 → 總統，全程 15～20 年 |
| **議員助理 / 幕僚** | ★★★★ | 28–35 | 私產依背景 ×1.2、競選經費 50 萬、知名度 1、老闆人脈、派系初始好感 +2、家鄉選區基層組織 2 | 接班參選議員或立委，再往上爬 |

兩種起點都必須從基層打起。這是刻意的——本遊戲的核心體驗是「爬上去」，直接空降的起點會把最好的部分跳過。

### 8.2 起點的第一個決定

開局第一回合，玩家面對三選一：

1. **加入大黨**（進步民主黨 / 中華國民黨）：資源多、限制多、要排隊
2. **加入小黨**（台灣民生黨 / 世代力量 / 本土基進黨 / 綠色社會黨 / 護家統一聯盟）：出頭快、天花板低、資源少
3. **無黨籍**：完全自由、無提名保障、無政黨補助、基層組織全靠自己

這個決定會塑造前 8 年的整個玩法。

### 8.3 種子系統

```js
// src/core/Rng.js
export function seedFromString(str) {
  let h = 0x811c9dc5;                         // FNV-1a
  for (const ch of str) {
    h ^= ch.codePointAt(0);
    h = Math.imul(h, 0x01000193) >>> 0;
  }
  return h >>> 0;
}
```

**種子決定什麼**

| 項目 | 說明 |
|---|---|
| NPC 生成 | 所有政治人物的姓名、屬性、派系歸屬、野心 |
| 初始微擾 | 22 縣市與 195 選區的數值在基準上 ±3% 擾動 |
| 派系起始配置 | 各黨派系的席次佔比與領袖 |
| 事件抽樣序列 | 同樣的條件下抽到哪一則事件 |
| 選舉隨機數 | §20.4 的 0.98～1.05 乘數序列 |
| 世界事件時程 | L3 重大轉折的觸發年份 |

**種子不決定什麼**：22 縣市的基準數值、法案效果、公式係數——這些是固定的規則，種子只擾動初始狀態與隨機序列。

**UI**
- 建角頁面有種子輸入框，留白則隨機生成 8 字元種子（大寫字母與數字）
- 種子顯示在主畫面設定頁，可複製分享
- 存檔記錄 `seed` 與 `rngCounter`，確保讀檔後的隨機序列完全一致
- 「重玩此種子」按鈕：用相同種子重開一局，世界完全一樣，只有玩家的選擇不同

**設計意圖**：讓玩家能說「我拿 K7X2M9QP 這個種子，2028 年會有一場能源危機，你自己試試看」。這是單機遊戲的社群黏著點。

## 9. 選區系統

### 9.1 為什麼要做到選區層級

支持度如果只算到縣市，玩家的所有努力都被平均掉了。做到選區層級，「你在哪裡跑攤」「你的服務處設在哪」「哪個里的樁腳是誰的」才會有意義。

### 9.2 選區資料

以 2022 年台灣縣市議員選舉區劃分為基準，共 **195 個選區**（含原住民選區），資料檔 `data/districts.json`。

```js
{
  id: "KHH-05",
  regionId: "KHH",
  name: "高雄市第五選舉區",
  areas: ["鳳山區"],
  seats: 9,                    // 應選議員席次
  type: "general",             // general | plainIndigenous | mountainIndigenous | indigenous
  population: 358000,
  urbanity: 4,                 // 0-5 都市化程度
  lean: -2,                    // -5 深綠 ~ +5 深藍
  pops: [ /* 30 個 POP，見 §13 */ ],
  grassroots: {                // 基層組織，0-5
    PDA: 3, CRP: 2, TPL: 1, NGF: 0, TWR: 1, GSP: 0, CUA: 0,
    _player: 0
  },
  playerFavor: 0,              // -5 ~ 5
  serviceOffice: false         // 玩家是否在此設服務處
}
```

**全國合計**：195 選區、913 席縣市議員、人口 2330 萬。

### 9.3 選舉層級如何聚合選區

| 選舉 | 計票範圍 |
|---|---|
| 縣市議員 | 單一選區（SNTV 複數當選） |
| 鄉鎮市長 / 里長 | 選區內的次級單位（以選區人口按比例拆分） |
| 立法委員（區域） | 由 1～3 個議員選區組合而成，`data/elections.json` 定義對應表 |
| 縣市長 | 該 regionId 的所有選區聚合 |
| 總統 | 全部 195 選區聚合 |
| 不分區立委 | 全國政黨票聚合，5% 門檻 |

### 9.4 基層組織

**每個選區、每個政黨（含玩家個人）各有一個 0～5 的基層組織值。**

| 級 | 語詞 | 意義 |
|---|---|---|
| 0 | 全無根基 | 沒有任何人幫你 |
| 1 | 零星據點 | 幾個熱心支持者 |
| 2 | 略有樁腳 | 有里長願意站台 |
| 3 | 組織綿密 | 服務處、志工、婚喪喜慶全覆蓋 |
| 4 | 盤根錯節 | 地方派系與宮廟系統都通 |
| 5 | 鐵板一塊 | 對手在這裡連場子都借不到 |

**成長**（慢）
- 選區跑攤：每 3 次 +0.2（有組織部長時 +0.3）
- 設服務處：每回合 +0.1，但每回合要花錢
- 里鄰建設配合款流向該選區：+0.3
- 該選區的地方議案通過且有感：+0.2
- 派系背書：直接 +1（借來的，派系翻臉會收回）

**衰退**（每回合）
- 未經營的選區：−0.05
- 有服務處但棄置：−0.02
- 醜聞爆發：全選區 −0.3
- 幕僚背叛帶走組織：該選區 −1

**作用**
```
動員強度 = 基層組織（玩家）× 0.6 + 基層組織（所屬政黨）× 0.4
投票率加成 = 1 + 動員強度 × 0.04          // 滿級約 +20%
個人票加成 = 動員強度 × 0.015              // 滿級約 +7.5% 得票
```

基層組織是**選舉真正的護城河**。民調領先但基層是 0 的候選人，會在投票日發現自己的支持者根本沒出門。

### 6.3 主要企業系統

**企業互動機制**
- 企業 `mood` 受法案（稅率、勞基法、環評、電價）影響
- `mood ≤ −3` → 觸發「出走 / 縮編 / 撤資」事件 → 該縣市就業與 GDP 下滑
- `mood ≥ +3` → 觸發「加碼投資 / 設廠」事件 → 建設與 GDP 上升，但可能引發環保 POP 反彈
- 企業會透過遊說系統（政治獻金、媒體投放）影響法案，玩家可接受或拒絕

### 6.4 股市系統

- **台股加權指數** = Σ(企業市值 × 權重) 的正規化值，開局約 22,000 點
- 企業市值受：產業景氣（世界系統）、法規（稅率、環評）、匯率、企業 mood、突發事件
- 大盤變動 → 影響中壯與退休 POP 的財富效果 → 影響消費、生活水準與政府滿意度
- **半導體權重佔比 40%+**：世界系統的「全球科技週期」是全遊戲最大的經濟槓桿

## 13. POP 傾向系統

參考《Victoria 3》的 POP 模型。切分方式：**選區 × 職業階層 × 世代**。

### 13.1 切分

- **選區**：195 個
- **職業階層（10 類）**：`farmer` 農漁民、`bluecollar` 藍領勞工、`service` 服務業、`whitecollar` 白領受薪、`techpro` 專業技術、`smallbiz` 小企業主、`capitalist` 大資本、`publicsvc` 軍公教、`student` 學生、`retiree` 退休族
- **世代（3 類）**：`youth` 18–34、`middle` 35–54、`senior` 55+

**195 × 10 × 3 = 5850 個 POP**，每個選區恰好 30 個。

「認同」不再作為切分維度，改為每個 POP 內部的分佈向量 `identityMix`，避免 POP 數量爆炸。

### 13.3 每回合演化

**步驟 1：生活水準**

```
realIncome = income / (1 + 累積通膨)
housingBurden = 該選區房價指數 × 階層係數 / realIncome

targetSoL = 5 × sigmoid(
      0.32 × norm(realIncome, 階層基準)
    + 0.20 × employmentRate
    + 0.18 × (1 − housingBurden)
    + 0.16 × 公共服務可及性(該縣市 infrastructure)
    + 0.08 × 環境品質
    + 0.06 × 治安
)
SoL += (targetSoL − SoL) × 0.12        // 慢速收斂，玩家感受得到落差但不會瞬變
```

**步驟 2：意識形態漂移**

```
對每一軸 axis：
  pull = 0.45 × 結構性利益(階層, 該軸)
       + 0.25 × 國家價值觀[axis]              // 社會氛圍的拉力
       + 0.20 × 媒體框架[axis]
       + 0.10 × 世代傾向
  ideology[axis] += (pull − ideology[axis]) × 0.025     // 月回合；週回合 ×0.25
  ideology[axis] = clamp(ideology[axis], −5, 5)
```

單一法案不會翻轉任何人的立場，需要持續數年的同向壓力。這是本系統的核心手感。

**步驟 3：政黨支持度**

```
對每個政黨 p：
  ideologicalFit = 1 − Σ_axis( |pop.ideology[a] − party.platform[a]| × axisWeight[a] ) / 40
  performance    = Σ_issue( issueWeights[issue] × 該黨在此議題的近期評價 )
  identityBonus  = Σ_identity( identityMix[i] × party.identityAppeal[i] )
  incumbentPenalty = 執政黨且 SoL 近 12 回合下降時的懲罰
  charisma       = 該黨在此選區的候選人魅力與知名度

  raw(p) = 0.38·ideologicalFit + 0.30·performance + 0.14·identityBonus
         + 0.10·charisma − 0.08·incumbentPenalty
partySupport = softmax(raw × 3.2)
```

**步驟 4：熱情度**（決定會不會出門）

```
top = 支持度最高的政黨
enthusiasm += ( 5 × ideologicalFit(top) × (0.6 + 0.4 × SoL/5) − enthusiasm ) × 0.15
若 top 近期做出違背此 POP 核心議題的決定 → enthusiasm −= 1.0
```

熱情度低的支持者仍然「支持」該黨，但**投票率會顯著下降**。這模擬「歸隊」與「含淚不投」，是選戰動員的真正對象。

**步驟 5：激進度**

```
militancy += (期望 SoL − 實際 SoL) × awareness/5 × 0.08 − 0.04（自然衰減）
militancy ≥ 3 → 抗議事件
militancy ≥ 4 且 stratum ∈ {bluecollar, service} → 罷工
militancy ≥ 4 且 stratum = student → 大規模學運
militancy ≥ 5 → 全國性社會運動，可能催生新政黨
```

### 13.4 玩家可見化

玩家不會看到 5850 個 POP，而是看到：

- **全國儀表板**：10 個階層的平均生活水準（四字語詞 + 趨勢箭頭）
- **選區頁**：該選區 30 個 POP 聚合成 5 張群體卡，寫明「他們現在最不爽的三件事」
- **法案預覽**：通過此法案，哪些階層受益、哪些受害（綠紅色塊，用語詞不用數字）
- **選情頁**：選區地圖著色 + 熱情度警示（「你的鐵票區今年沒什麼人想出門」）

## 14. 國家價值觀系統

參考《Europa Universalis V》的 Societal Values：8 條對立軸，移動極慢，一旦形成則深刻改變國家的運作方式。

### 14.1 八條軸（−5 ~ +5）

| # | 軸 | 負端 | 正端 | 2026 開局值 |
|---|---|---|---|---|
| 1 | `centralization` | 地方自治 | 中央集權 | +1 |
| 2 | `unification` | 本土認同 | 傾向統合 | −1 |
| 3 | `marketFreedom` | 國家干預 | 自由市場 | +1 |
| 4 | `progressivism` | 傳統價值 | 進步價值 | +2 |
| 5 | `immigration` | 邊境管制 | 開放移民 | −1 |
| 6 | `environment` | 發展優先 | 環境優先 | 0 |
| 7 | `militaryAutonomy` | 依賴同盟 | 軍事自主 | −1 |
| 8 | `directDemocracy` | 菁英治理 | 直接民主 | +1 |

**呈現方式**：`方向詞・強度詞`，例如 `unification = −4` 顯示為「**本土認同・主流共識**」。

強度詞：`0 勢均力敵｜1 微弱傾向｜2 略有傾向｜3 明顯偏向｜4 主流共識｜5 舉國一致`

### 14.2 移動機制

- 引擎內部保留小數，**月回合每軸最多移動 ±0.02**（一年 ±0.24，一屆任期 ±0.96）
- 也就是說，**推動一條軸跨越一整級，需要約 4～5 年的持續施力**
- 推力來源：
  - **法案**：通過法案 → 對應軸產生持續推力，持續 24～72 回合
  - **POP 意識形態均值**：全國 POP 在該軸的人口加權平均，每回合貢獻 0.004 的拉力
  - **重大事件**：L3／L4 事件可一次性推 ±0.3～±1.2
  - **教育與媒體**：課綱、公共媒體預算等長期政策，微弱但永續
  - **玩家主動投資**：花 150 政治資本推動社會運動，一次 +0.15

### 14.3 修正效果

每條軸依所在級數提供修正。以 `marketFreedom` 為例：

| 級數 | 修正 |
|---|---|
| +4 ~ +5 | 企業 mood +1.5、GDP 成長 +0.4%、稅收彈性 +10%；吉尼係數每年 +0.008、藍領 SoL −0.6、罷工機率 +40% |
| +2 ~ +3 | 企業 mood +0.6、GDP 成長 +0.15% |
| −1 ~ +1 | 無修正 |
| −3 ~ −2 | 公共服務可及性 +0.5、吉尼係數每年 −0.004、企業 mood −0.8 |
| −5 ~ −4 | 公共服務 +1.2、吉尼每年 −0.01、GDP 成長 −0.5%、企業出走機率 +50% |

以 `militaryAutonomy` 為例：

| 級數 | 修正 |
|---|---|
| +4 ~ +5 | 國防自製率 +2 級、不對稱戰力 +1.5 級、國防預算需求 +25%；美國關係 −1 級、財政壓力大增 |
| −5 ~ −4 | 美國關係 +1.5 級、軍購成本 −15%、國防自製 −2 級；疑美論事件機率 +30%、本土 POP 不滿上升 |

以 `unification` 為例：

| 級數 | 修正 |
|---|---|
| +3 以上 | 中國大陸關係 +2 級、觀光與農產出口 +12%；美日關係 −1.5 級、本土 POP militancy +1、國際支持 −1 級 |
| −3 以下 | 美日關係 +1 級、國際能見度 +1 級；中國大陸軍事壓力 +1.5 級、經濟脅迫事件 +50%、統派 POP militancy +1.5 |

其餘五軸的完整修正表在 `data/values.json`，格式相同。

### 14.4 社會共識鎖定

某軸絕對值達 4 以上且持續 60 個月回合 → 進入「社會共識」狀態：
- 反向移動速度減半
- 該方向的法案通過門檻降低 15%
- UI 上該軸加註「這件事已經沒什麼人在爭了」

### 15.4 黨內權力鬥爭

玩家可挑戰 **黨團總召 → 副主席 → 黨主席** 三級黨職。

```
勝算 = 黨內聲望 × 0.35
     + Σ(派系 favor 正規化 × 派系席次佔比) × 0.35
     + 全國知名度 × 0.15
     + 全國好感度 × 0.15
     − 汙名印象 × 0.10
```

當上黨主席可：調整黨綱座標（每年 1 軸 ±1）、決定提名名單、動用黨庫、指揮全國基層組織資源。

### 15.5 政黨動態

- **分裂**：`cohesion ≤ 1` 且某派系對現任主席 favor ≤ −4 → 出走成立新黨，帶走席次與該派系經營選區的基層組織
- **合併**：兩個小黨席次 < 8、平台距離 < 8（8 軸曼哈頓距離）、皆面臨泡沫化 → 協商合併
- **泡沫化**：連續兩次選舉政黨票 < 2% 且席次 < 3 → 解散
- **新生**：某議題的 POP militancy 持續 ≥4 且現有政黨皆無法回應 → 新政黨誕生（如「居住正義黨」）

## 16. 立法院系統與 25 條可修改法律


### 12.1 立法院結構

- 總席次 **113**：區域 73 + 原住民 6 + 不分區 34（政黨票 5% 門檻）
- **8 個常設委員會**：內政、外交及國防、經濟、財政、教育及文化、交通、司法及法制、社會福利及衛生環境
- 玩家為立委時可選擇加入 1–2 個委員會，該領域法案影響力 ×1.5
- **黨團協商制**：爭議法案進入協商，需跨黨談判（`談判` 屬性檢定）

### 12.2 法案流程

```
提案（玩家 / NPC / 行政院）
  → 一讀（付委）
  → 委員會審查（可修正、可擱置）
  → 黨團協商（爭議法案，1 個月冷凍期）
  → 二讀（逐條表決）
  → 三讀（全案表決）
  → 公布施行（下回合起數值生效，部分法案有 3–12 回合延遲）
  → 【覆議 / 釋憲】可選分支
```

**通過率計算**

```
支持席次 = Σ(各黨席次 × 該黨支持機率)
該黨支持機率 = base(黨綱與法案的意識形態距離)
             + 派系動員修正（玩家 favor）
             + 民意壓力修正（該法案在 POP 中的支持度）
             + 政治資本強推（玩家可花費，每 50 點 +3%，上限 +18%）
             + 交換條件修正（跨黨交易）
             − 跑票率(1 − cohesion/5)
```

### 12.3 25 條可修改法律

每條法律有 **3–5 個檔位**，玩家可提案修改。表中「檔位」由左（保守/低）到右（激進/高）。

### 13.3 地方 vs 中央的張力

當中央與地方分屬不同政黨時，觸發專屬機制：

- **統籌分配款博弈**：中央可依 `財劃法` 檔位與政治考量調整分配，地方首長可公開抗議
- **中央補助卡關**：地方大型建設需中央核定，可被政治性拖延
- **權責爭議事件**：疫情、災害、環保稽查時的權責推諉，雙方民調互相消耗
- 玩家在地方時可累積「對抗中央」的英雄形象（本土 POP 好感 ++），但實質建設受阻

## 18. 質詢系統

質詢是本遊戲最具戲劇張力的場景，也是知名度最快的來源。

### 18.1 質詢類型

| 類型 | 場合 | 玩家角色 |
|---|---|---|
| 立法院總質詢 | 每會期開議後 2 個月 | 立委（提問）／閣揆或部長（答詢） |
| 委員會質詢 | 會期中每回合可 1 次 | 立委／部會首長 |
| 議會總質詢 | 地方定期會 | 議員／縣市長或局處長 |
| 記者會攻防 | 任意時機 | 任何身分 |

### 18.2 提問方流程

```
① 選議題（從熱門議題池 + 情報卡中挑選）
② 選準備度（先前的「質詢準備」行動決定基礎加成）
③ 選質詢風格（5 選 1，部分風格受氣魄限制）
④ 三回合攻防，每回合選一個追問方向
⑤ 對手應對檢定
⑥ 結算
```

**五種風格**

| 風格 | 主屬性 | 氣魄門檻 | 成功效果 | 失敗風險 |
|---|---|---|---|---|
| 理性論述 | 判斷 | — | 專業形象 +1、白領與科技 POP 好感 ++ | 沒有媒體聲量，等於白做工 |
| 激烈對撞 | 口才 | ≥3 | 媒體聲量 +2、同溫層好感 +2 | 中間選民好感 −1、被貼「作秀」標籤 |
| 數據轟炸 | 判斷 + 情報品質 | — | 對手形象重創、法案推動壓力 +2 | 數據有誤則專業與清廉雙重挫 |
| 道德訴求 | 魅力 | — | 全民好感 +1、議題設定成功 | 被反問「你自己呢」→ 汙名 +0.3 |
| 爆料 | 情報 + 氣魄 | ≥4 | 對手直接進入醜聞狀態、聲量爆表 | 爆料不實則官司纏身、汙名 +0.5、清廉印象 −2 |

**檢定公式**

```
玩家分 = 主屬性 × 8 + 準備度 × 10 + 情報品質 × 6 + 議題熱度 × 3
       + 政策幕僚能力 × 4 + rand(−10, 10)
對手分 = 對手應對力 × 8 + 對手準備 × 8 + 執政資源 × 5 + rand(−10, 10)

差值 ≥ +30 → 大成功（全國頭條、片段瘋傳）
差值 +10 ~ +29 → 成功
差值 −9 ~ +9  → 平手（無聲量）
差值 −29 ~ −10 → 失敗（被打臉）
差值 ≤ −30 → 大失敗（成為對手的宣傳素材）
```

### 18.3 答詢方流程

玩家為部長／閣揆／縣市長時被質詢：

| 策略 | 氣魄門檻 | 效果 | 風險 |
|---|---|---|---|
| 正面詳答 | — | 專業形象 +，數據站得住則反殺 | 施政確有問題時傷害擴大 |
| 承諾改進 | — | 短期止血、民怨降溫 | 記入承諾清單，跳票反噬加倍 |
| 迴避轉移 | ≤3 | 傷害減半 | 「答非所問」標籤、中間選民 −1 |
| 強硬反擊 | ≥3 | 同溫層好感 +2、氣勢壓制 | 中間選民 −2、議場衝突事件 |
| 切割下屬 | — | 個人傷害轉嫁 | 文官士氣 −2、幕僚忠誠 −1、汙名 +0.4 |

### 18.4 承諾清單

質詢中做出的每個承諾都被記錄，附帶截止回合。到期未達成 → 媒體與對手發動跳票攻擊：該議題相關 POP 好感 −1、熱情度 −1、汙名 +0.3。

這是本遊戲的長期誠信帳本，與汙名印象一起構成「你說過的話會回來找你」的機制。

## 19. 預算系統


### 15.1 中央總預算

**歲入模型**

```
歲入 = 綜所稅 + 營所稅 + 營業稅 + 貨物稅 + 關稅 + 證交稅
     + 土增稅 + 遺贈稅 + 菸酒稅 + 其他 + 規費 + 國營事業盈餘

各稅 = 稅基 × 稅率 × 徵收率
稅基由 GDP、薪資總額、企業獲利、股市成交量、進口值等驅動
```

**歲出 12 大科目**（玩家可調整配置）

| 科目 | 開局佔比 | 調整影響 |
|---|---|---|
| 社會福利 | 24.5% | 各階層 SoL、年金與健保永續 |
| 教育科學文化 | 19.0% | 教育數值、長期人力資本、`progressivism` |
| 國防 | 15.5% | 戰備、不對稱戰力、美國關係 |
| 經濟發展 | 12.0% | 產業補貼、基礎建設、GDP 成長 |
| 一般政務 | 9.5% | 行政效率、文官士氣 |
| 債務付息 | 6.0% | 剛性，隨國債上升 |
| 補助地方 | 5.5% | 22 縣市財政 |
| 交通建設 | 4.0% | 各縣市 transport |
| 環境保護 | 2.0% | 空污、碳排、`environment` |
| 農業 | 1.5% | 農民 SoL、糧食自給 |
| 司法 | 0.5% | 治安、司法信任 |
| 預備金 | 0.5% | 災害應變彈性 |

**編列與審查流程**

```
8 月：行政院提出（玩家執政時可調整配置）
9-11 月：立法院各委員會審查
   - 在野黨提出刪減與凍結提案（每案需表決）
   - 玩家可用政治資本、法案交換、派系動員擋下刪減
12 月：三讀通過（或不通過 → 依前年度預算執行，行政受限）
隔年 1 月起：執行，執行率影響實際效果（執行率 = f(行政效率, 文官士氣, 工程能量)）
```

**特別預算**：可另立（前瞻建設、國防特別、災後重建、產業紓困）。特別預算不受歲出額度限制但直接舉債，短期效果強、長期債務壓力大。這是遊戲中最誘人的陷阱。

### 15.2 地方預算

```
可支配財源 = 自有財源 + 統籌分配款 + 中央補助款 + 舉債額度 − 剛性支出（人事費 + 債息 + 法定社福）

剛性支出佔比：直轄市約 55–65%，財政困難縣市可達 80–90%（皆為具體數值）
```

**財政困難機制**：當某縣市 `剛性支出 / 總財源 > 0.85`，進入「財政困難」狀態：
- 無法舉辦新建設，只能維持
- 首長支持度每回合 −1
- 觸發「發不出薪水」「向中央求援」事件鏈
- 玩家為該縣市首長時，主要玩法變成「開源節流 + 向中央爭取」的生存挑戰

### 15.3 預算作為政治武器

| 手段 | 使用者 | 效果 |
|---|---|---|
| 刪減對手縣市補助 | 執政方 | 該縣市建設停滯，但地方 POP 對中央不滿 ++ |
| 凍結預算 | 在野方 | 要求行政部門先提報告，拖延政策 3–6 回合 |
| 主決議附款 | 在野方 | 強制行政部門執行某政策（軟性立法） |
| 特別預算綁樁 | 執政方 | 指定縣市大型建設 → 該縣市好感 ++、財政紀律印象 − |
| 全案退回 | 在野方（需過半） | 憲政對決事件，雙方民調都受傷，社會信任 −− |

### 20.1 選舉層級

| 選舉 | 週期 | 選制 | 計票範圍 |
|---|---|---|---|
| 村里長 | 4 年 | 相對多數 | 選區次級單位 |
| 鄉鎮市民代表 | 4 年 | 複數選區 | 選區次級單位 |
| 縣市議員 | 4 年 | SNTV 複數選區 | 單一議員選區 |
| 鄉鎮市長 | 4 年 | 相對多數 | 選區次級單位 |
| 縣市長 | 4 年 | 相對多數 | 該縣市全部選區 |
| 立法委員（區域） | 4 年 | 單一選區相對多數 | 1～3 個議員選區組合 |
| 立法委員（不分區） | 4 年 | 政黨名單比例代表，5% 門檻 | 全國 |
| 總統副總統 | 4 年 | 相對多數 | 全部 195 選區 |

### 20.2 投票率模型

```
turnout(pop, election) =
    pop.turnoutBase                                  // 具體數值，0.55 ~ 0.78
  × (1 + pop.awareness / 5 × 0.15)                   // 政治覺醒度
  × levelFactor[election.level]                      // 總統 1.15 / 縣市長 1.05 / 立委 1.00 / 議員 0.90 / 里長 0.75
  × (1 + mobilization(pop.districtId, candidate) × 0.04)   // 動員強度 0-5
  × enthusiasmFactor(pop, candidate)                 // 見下
  × weatherFactor                                    // 投票日天氣事件，0.92 ~ 1.03

enthusiasmFactor = 0.72 + 0.056 × pop.enthusiasm     // 熱情 0 → 0.72；熱情 5 → 1.00
```

**熱情度是選戰的主戰場**。民調上的「支持度」不會因為你辦一場造勢就提高，但熱情度會——而熱情度直接決定那些支持者會不會真的出門。這解釋了為什麼領先的候選人還是要拚場、要催票。

### 20.3 得票模型

```
P(pop → 候選人 c) = normalize(
      pop.partySupport[c.party] × 0.55
    + personalFactor(c, pop) × 0.30
    + mobilization(pop.districtId, c) / 5 × 0.15
  ) × issueShockModifier

personalFactor = 0.30 × 知名度/5
               + 0.25 × 該選區好感度正規化
               + 0.20 × 魅力/5
               + 0.15 × 地緣（家鄉選區、同縣市）
               − 0.10 × 汙名印象/5
               + 標籤修正（例如 TAG_LABOR_FRIEND 對藍領 POP +0.08）
```

### 20.4 最終得票

```
votes(c, district) =
    Σ_pop [ pop.size × turnout(pop, election) × P(pop → c) ]
  × rand(0.98, 1.05)        // ★ 每個候選人、每個選區各擲一次
```

這個乘數模擬所有模型抓不到的東西：投票日的意外、地方人情、最後一週的耳語、開票的統計噪音。範圍刻意設計成 **不對稱（下限 −2%、上限 +5%）**，因為政治的意外通常是「爆冷」而不是「爆穩」。

在 SNTV 複數選區，這個乘數會讓配票精算的候選人有落馬風險——這正是真實選舉的樣子。

### 20.5 競選階段（週回合模式）

選前 2 個月進入週回合，AP 仍為 2，但解鎖競選專屬行動：

| 行動 | AP | 經費 | 疲勞 | 效果 |
|---|---|---|---|---|
| 掃街拜票 | 1 | 5 萬 | 12 | 該選區好感 +、熱情度 + |
| 大型造勢 | 2 | 200 萬 | 20 | 全區熱情度 ++、動員強度 ++、下雨風險 |
| 電視廣告 | 1 | 500 萬 | 5 | 知名度 +、全區好感 + |
| 網路投放 | 1 | 80 萬 | 5 | 青年 POP 熱情 ++、精準投放 |
| 政見發表 | 1 | 20 萬 | 12 | 口才檢定，中間選民好感大幅波動 |
| 負面文宣 | 1 | 150 萬 | 12 | 對手熱情度 −−；自身清廉 −、反彈風險 |
| 配票操作 | 2 | 50 萬 | 15 | SNTV 席次最大化；失誤則同黨互相拉下 |
| 危機處理 | 2 | 依情況 | 20 | 應對選前爆料 |
| 拜廟與地方拜會 | 1 | 30 萬 | 12 | 基層組織 +、年長 POP 熱情 + |

**選前之夜**：最後一個週回合的特殊場景，一次決策可造成 ±3% 的得票擺盪。

### 20.6 提名戰（黨內初選）

正式選舉前 8 個回合進行：

- **民調式初選**：`選區好感度 × 0.55 + 全國知名度 × 0.45`
- **黨員投票**：`黨內聲望 × 0.5 + Σ(派系 favor 正規化 × 該派系黨員佔比) × 0.5`
- **徵召協調**：黨主席直接決定

初選落敗可選擇：接受（黨內聲望 +1）、脫黨參選（黨內聲望歸零、分裂票源、基層組織保留 50%）、退居輔選（保留政治資本，換取下次優先）。

## 21. 事件、媒體與輿論系統

### 21.1 事件驅動架構

事件不是隨機罐頭，而是由數值閾值觸發並填入當前世界狀態。完整 schema 見《項目計畫文檔》§4.4。

事件庫規模：MVP 96 則（已完成），1.0 版 400 則以上。分類：經濟、能源、兩岸、外交、災害、社會、醜聞、黨內、選舉、媒體、個人生活、世界。

### 21.2 事件文本寫作規範（強制）

**這一節是硬規範，所有事件文本必須通過 `tools/validate_events.js` 的自動檢查。**

1. **非特殊情況下，禁止任何一個句子少於 7 個字。** 句子以「。！？；」為切分單位，扣除標點後計字。唯一例外是引號內的人物直接對白。
2. `headline` 寫成真實新聞標題的口吻，14～26 字，單句。
3. `body` 兩到三句，每句 20 字以上，要有具體的人事時地物。
4. `hint`（選項的方向預告）至少 12 字，給方向不給數字。
5. `text`（選項本身）8～20 字，寫玩家的具體作為，不是抽象態度。
6. **每則事件至少 3 個選項，且沒有明顯最優解**——每個選項的代價必須落在不同維度。
7. 不得出現真實人名、政黨名、企業名、媒體名。
8. 不做立場宣導，同一議題的正反方都要有站得住腳的論述。

**為什麼定第 1 條**：短句堆疊是機器寫作最明顯的痕跡。「他答應了。事情很快傳開。輿論炸鍋。」——這種節奏在中文新聞與小說裡都不自然。強制句長會逼出完整的敘述句，文本立刻像人寫的。

### 21.3 議題熱度

系統維護 12 大議題的熱度（0～5，四字語詞）：
`經濟 物價 房價 就業 治安 能源 環境 兩岸 國防 貪腐 醫療 教育`

語詞：`0 乏人問津｜1 偶有耳聞｜2 略受關注｜3 議論不休｜4 沸沸揚揚｜5 舉國譁然`

- 熱度由事件、數值劇變、媒體報導推升，每月回合自然衰減 −0.25
- 熱度高的議題在 POP 的 `issueWeights` 中臨時加權 ×(1 + 熱度 × 0.12)
- 選舉時最熱的 3 個議題決定選戰主軸
- **議題設定權是玩家的核心戰略資源**：透過記者會、質詢、法案提案主動推升對自己有利的議題

### 21.4 媒體

12 家媒體，各有 `bias`（−5 綠 ~ +5 藍）、`credibility`（0～5）、`reach`（0～5）、`playerRelation`（−5～5）。

同一事件，不同媒體產出不同框架的標題。玩家看到的新聞版面因此有真實的立場感。

**特殊媒體行為**
- `西林電視`：`bias` 每季重算為「當前聲量較高一方」的方向——它跟風，不領風
- `公立傳播`：`bias` 恆等於當前執政黨的方向，但 `credibility` 隨政黨輪替下滑
- `ByTok` / `TeD`：`reach` 對 youth 世代 ×2，對 senior 世代 ×0.4；假訊息傳播係數最高

**假訊息機制**：`數位傳播法` 檔位低時，境外與匿名假訊息在選前 3 個週回合造成 ±2～5% 的得票擾動，且優先攻擊玩家的汙名紀錄。

### 21.5 醜聞

汙名印象是永久紀錄，醜聞則是**當下的火**。

```
每回合：若 汙名印象 ≥ 2，以 (汙名 − 1.5) × 12% 的機率觸發調查事件
調查事件 → 檢調偵辦鏈（3～8 回合）→ 起訴／不起訴
起訴 → 清廉印象 −2、汙名 +1.5、政黨要求切割、可能停權
定罪 → 生涯結束，進入結局結算
```

**危機處理選項**：花費政治資本、動用派系護航（需 favor ≥4）、找替罪羊（汙名 +0.4、幕僚忠誠 −1）、主動請辭止血（職位沒了，但汙名不再增加）。

## 24. 數學模型附錄

### 24.1 縣市 GDP 成長

```
gdpGrowth(region) =
    baseGrowth
  + Σ_sector( sectorShare × sectorGlobalCycle )        // 世界系統驅動
  + infrastructureBonus( transport, energy, digital )   // 抽象 0-5 轉係數
  + laborSupplyEffect( workingAgeRatio, employmentRate )
  + policyEffect( 稅率, 補貼, 法規成本 )
  + corpInvestmentEffect( Σ corpMood )
  − disruptionPenalty( 罷工, 天災, 缺電, 缺水 )
```

### 24.2 通膨

```
inflation = 0.40 × 進口成本傳導( 匯率, 國際能源價格 )
          + 0.30 × 需求拉動( gdpGrowth, 貨幣成長 )
          + 0.20 × 薪資成本( 最低工資, 勞動法規 )
          + 0.10 × 預期心理( 前 3 回合平均 )
```

### 24.3 生活水準（抽象 0～5）

見 §13.3 步驟 1。核心是 `5 × sigmoid(加權和)`，確保極端值不會失控。

### 24.4 民調支持度（具體百分比）

```
approval(玩家) =
    0.32 × Σ_pop( pop.size × normalize(pop.playerFavor) ) / 總人口
  + 0.24 × 近 6 回合全國 SoL 變化趨勢
  + 0.20 × 熱門議題上的立場與民意契合度
  + 0.12 × 個人形象（清廉印象 − 汙名印象 × 1.5）
  + 0.12 × 媒體框架淨值
  ± houseEffect(各家民調 ±3%)
```

### 24.5 抽象量的內部精度

所有 0～5 的抽象量在引擎內部以 **float** 儲存，顯示時取整。這讓「累積了很久但還沒跨級」的狀態成立——UI 會顯示「略有鬆動」提示玩家快要跳級了。

### 24.6 平衡目標值

| 指標 | 目標 |
|---|---|
| 一屆任期內全國平均 SoL 可改變幅度 | ±0.6 級（大刀闊斧）／±0.2 級（穩健施政） |
| 單一法案對單一階層的 SoL 影響 | ±0.1～0.4 級，極端法案 ±0.7 級 |
| 國家價值觀單軸一屆任期最大移動 | ±0.96 級（約一級） |
| 基層組織從 0 到 3 所需時間 | 約 40 個月回合的持續經營 |
| 現任優勢 | +4% 得票，施政失敗時反轉為 −8% |
| 完整生涯（素人 → 總統）最短可能 | 14 年，平均 20 年 |
| 每回合玩家決策數 | 3～6 個（AP 2 + 事件 1～4） |
| 一屆任期內住院次數期望 | 0.4 次（正常操作）／1.8 次（極限操作） |

## 25. 民調公司系統

### 25.1 核心原則

**民調不會憑空出現，要有人做才有。** 開局時玩家手上沒有任何數字，首頁會老實承認這件事：
「最近沒有任何一家民調公司做過調查，你手上也沒有自己的數字。在這一行，不知道自己站在哪裡，比站得不好還危險。」

### 25.2 九家民調公司

| 公司 | 房效應 | 公信力 | 有效樣本 | 設計效果 | 非抽樣偏差 | 頻率 |
|---|---|---|---|---|---|---|
| 燦爛島電子報民調 | −2 綠 | 4 | 1,073 | 1.15 | 0.6 | 每月 |
| 山海民意調查中心 | +2 藍 | 4 | 1,210 | 1.20 | 0.7 | 每月 |
| 蓋皮尤國際研究 | 0 | 5 | 1,580 | 1.05 | 0.3 | 每季 |
| 聯日報民調中心 | +3 藍 | 3 | 936 | 1.35 | 1.2 | 每兩月 |
| 明淨民調中心 | −3 綠 | 3 | 912 | 1.35 | 1.2 | 每兩月 |
| 政智大學選研中心 | 0 | 5 | 1,905 | 1.02 | 0.2 | 每半年 |
| 中華民意基金 | −2 綠 | 4 | 1,078 | 1.18 | 0.6 | 每兩月 |
| 匯流快訊民調 | +1 | 2 | 618 | 1.45 | 1.6 | 每月 |
| PTC 網路快篩 | −1 | 1 | 4,200 | 1.00 | 7.5 | 每月 |

### 25.3 誤差用統計學算，不手填

```
最大誤差（95% 信心水準） = 1.96 × √(0.25 / n) × √設計效果
各黨讀數的抽樣誤差       = 1.96 × √(p(1−p) / n) × √設計效果
```

這條公式解決了一個實際的問題：**支持度 3% 的小黨，誤差只有 ±0.6～1.6 個百分點，不會憑空跳到兩位數。**
過去手填一個 `sampleError: 9` 給網路民調，結果是每一份民調裡的小黨都在 0% 到 12% 之間亂跳，那是錯的——
網路民調的問題不在樣本數（它的樣本往往比電話民調大），而在**自我選擇偏差**，所以拆成兩個獨立的參數：

- `sampleSize` + `designEffect` → 抽樣誤差，統計學算得出來
- `nonSamplingBias` → 題目設計、加權方式、自我選擇造成的系統性偏差，這才是網路民調真正的問題

PTC 網路快篩的樣本有 4,200 份、抽樣誤差只有 ±1.5%，但非抽樣偏差高達 7.5——數字很精確地錯著。

### 25.4 房效應

`bias` 為正偏藍、為負偏綠。房效應只在藍綠之間搬動，而且**按各黨的規模等比例分配**，不會把小黨吹大。
實測：同一時間點，聯日民調讀出的華復是 40.2%，明淨民調讀出的是 33.3%。

### 25.5 知名度門檻

**知名度低於「小有名氣」（2 級）時，全國民調根本不會把玩家列進題目裡。**
這是知名度在遊戲裡最真實的一道門檻——你不是支持度低，你是不存在。

### 25.6 委託內參民調

玩家可花競選經費委託：誤差乘 0.45、無房效應、不對外公布（因此不影響輿論）。
可指定全國／縣市／選區三種範圍，價格依範圍縮放。同時只能有一份委託在跑。


## 27. 組織理論系統

### 27.1 為什麼要有這個

政治人物的專業不是一條屬性條，是**他手上有沒有一套講得出來的東西**。
「進修讀書」改成「組織理論」之後，這個行動的產出從一個看不見的數字，變成一份可以拿出來用的資產。

### 27.2 二十套理論

每套理論涵蓋一個議題領域，並帶有明確的意識形態方向。同一個議題有立場相反的兩套，
所以綠營玩家跟藍營玩家會組出完全不同的工具箱：

| 議題 | 一種立場 | 相反立場 |
|---|---|---|
| 居住 | 只租不售的社宅路線 | 供給導向的住宅鬆綁 |
| 能源 | 分散式綠能與需量管理 | 核能延役的過渡論 |
| 勞動 | 工時縮減與生產力重估 | 彈性化與中小企業存續 |
| 國防 | 不對稱戰力優先論 | 同盟嵌合與聯合作戰 |
| 兩岸 | 去風險與供應鏈重組 | 交流促穩定論 |

每套理論有 `claims`（可引用的具體論點）、`axis`（會把國家價值觀往哪推）、
`strataAppeal`（哪些人聽了會買單）。

### 27.3 組織、使用、完善

```
組織：花「組織理論」行動，需要 (3 + 難度 − 2) 次才成形
使用：政論節目引用、選舉提政見、質詢當論據
完善：每使用一次 level +0.34（0～5）
引用加成 = (0.6 + level × 0.5) × (對題 1.6 / 不對題 0.7)
```

**講過十次的東西，一定比第一次講的圓熟。** 這是這個系統唯一想表達的事。

## 30. 退場、結算與事後談

### 30.1 生涯結算

```
成就分數 = 最高職位等級 × 12 + 勝選次數 × 6 + 推動法案 × 9
        + clamp(生活水準變化 × 30, −25, 40) + clamp((知名度−1) × 4, 0, 16)
        + 完善理論數 × 4 − 汙名 × 7 − 敗選次數 × 2
```

四個層級：`留下名字的人（≥90）｜做過事的人（≥55）｜努力過的人（≥25）｜被遺忘的人`

### 30.2 事後談刻意造成遺憾

這是本系統唯一的設計目的：

> **一個沒有留下什麼的人，退休之後只能看著這個國家往他反對的方向走，而且沒有人會記得他曾經反對過。**

實作方式：取玩家建角時立場最鮮明的三條價值觀軸，
- **成就分數 ≥55**：那三條軸的敘述往**玩家相信的方向**寫
- **成就分數 <55**：往**相反方向**寫，並在最後補上一句遺憾

每條軸各有兩組敘述（正向與負向），且**兩組都寫出了代價**——
往玩家的方向走不代表結局圓滿，只代表他相信的那件事真的發生了，連同它的副作用。

例如「地方自治」軸：

> 正向：地方拿回了財源與權限，縣市長不用再為了一筆補助跑中央，但南北的差距也拉得更開了。
> 負向：中央的權力比你在的時候更集中了，地方政府連一條路要怎麼修都得先上台北跑一趟。

遺憾的那一句：

> 他偶爾會在電視上看到這些新聞。年輕的時候他相信的不是這樣，但他已經沒有位子可以說話了。

## 32. 價值觀系統（v0.5 重寫）

### 32.1 十三條國家價值觀軸

| id | 負端 | 正端 | 2026 開局 |
|---|---|---|---|
| centralization | 地方自治 | 中央集權 | +1 |
| unification | 本土認同 | 傾向統合 | −1 |
| marketFreedom | 國家干預 | 自由市場 | +1 |
| progressivism | 傳統家庭 | 多元平權 | +2 |
| genderRoles | 男主外女主內 | 性別平權 | +2 |
| immigration | 邊境管制 | 開放移民 | −1 |
| environment | 環保騙局 | 重視環保 | 0 |
| equality | 發展優先 | 平等優先 | 0 |
| militaryAutonomy | 依賴同盟 | 軍事自主 | −1 |
| directDemocracy | 菁英治理 | 直接民主 | +1 |
| punishment | 寬容教化 | 嚴刑峻法 | +2 |
| fiscalExpansion | 財政保守 | 大力建設 | 0 |
| investmentPriority | 公共建設 | 產業投資 | +1 |

進步保守之所以要拆成兩條，是因為在台灣這兩件事確實會分開：
有人支持女性當到執行長，同時反對同性婚姻。把它們壓成一條軸，
這一群人在模型裡就會消失，而他們在現實裡是關鍵少數。

環境軸的改寫更重要。原本的「發展優先↔環境優先」把兩件事混在一起：
一件是要不要為環境付代價，另一件是相不相信環境問題是真的。
新的負端不是主張污染，而是把碳費、綠電與環評當成收費名目——
這才是這條軸在台灣真正的爭論。被拆出來的「發展↔平等」則獨立成軸。

### 32.2 兩岸態度的七個維度

統獨是這座島上最多人在意的一件事，壓成一條線太粗糙。
`data/china.json` 把它展開成七個彼此獨立的維度：

| 維度 | 負端 | 正端 | 權重 |
|---|---|---|---|
| friendly | 抗中保台 | 友中求和 | 1.00 |
| strength | 外強中乾 | 難以撼動 | 0.55 |
| morality | 極權為惡 | 同胞善意 | 0.70 |
| culture | 文化排斥 | 同文同種 | 0.60 |
| openness | 拒之門外 | 來者不拒 | 0.65 |
| usTrust | 疑美主義 | 堅信盟友 | 0.75 |
| japanTrust | 舊恨難消 | 唇齒相依 | 0.40 |

這七個維度是獨立的：可以認為對岸很強但沒有惡意，
也可以欣賞那邊的文化同時反對開放陸資。

### 32.3 理由不等於方向

每個 POP 另外帶一個「主要理由」（經濟利害、政治體制、同文同種、安全存亡、民主價值）。
關鍵設計是：**理由不決定立場，只決定什麼樣的說法打得動這個人。**

主張友中有利經濟的人，跟主張抗中才保得住經濟的人，在模型裡同屬 `economy` 這一類。
所以同一則經濟新聞會**同時強化這兩群人原本的立場**，而不是把他們推往同一個方向。
這就是為什麼在這個議題上講道理很少能說服任何人，而模型必須把這件事做出來。

論述打進 POP 時，理由對得上的人受到的影響是對不上的人的 4.9 倍
（`onReason 2.2` 對 `offReason 0.45`）。

### 32.4 男女差異

POP 刻意不切成男女兩份——那會讓 POP 數與存檔同時翻倍，
換來的資訊卻只有一個比例。改成每個 POP 帶一個 `femaleShare`，
算支持度時用同一組意識形態加減性別落差算兩次，再按比例混合。

落差再乘上世代倍率：**青年 1.75 倍、中壯 1.0 倍、樂齡 0.45 倍**。
這個設計反映的是台灣（以及全球）正在發生的事：性別政治落差幾乎全部集中在年輕世代，
長輩之間反而很小。也就是說，這件事是新的，而且還在擴大。

## 34. 跑攤場景庫

玩家連續跑六十次都不會看到同一段話。

### 34.1 為什麼要先擲結果再挑場景

順序反過來的話，同一個場景的三種結果會互相排擠，
玩家在鄉下選區跑不到二十次就開始看到重複。
所以流程是：先由屬性擲出這一次的表現，再從還沒出現過這個結果的場景裡挑一個。
本地跑完了就把範圍往鄰近鄉鎮放寬（候選人本來就會這樣跑），
真的全部跑遍了才把結果往旁邊挪一格——跑遍所有場子都是同一種收穫，本來也不合理。

六種都市化程度全部驗證過都能湊出 60 段不重複。

### 34.2 常駐通告

表現漂亮而且基層夠厚的場子，對方會問你要不要固定來（每次 16% 機率，最多三個）。
答應之後這個場子每回合自動扣一點行動點、穩定產出基層，**而且不再跳文本**——
同一段話看第二次，就是在浪費玩家的時間。

## 35. 人情牽制

這一行真正的貨幣不是錢也不是政治資本，是誰欠誰。
`favor` 是有號的：正值代表對方欠你，負值代表你欠對方，每回合衰減 3.5%。

- **握著別人的人情**：募款飯局、初選提名、樁腳名單、壓下新聞、危機示警
- **欠著別人的人情**：安插工作、關說個案、要你站台、要你投票

拒絕請託不會被罰錢，但那筆人情會直接翻成怨，對方的關係轉為 `rival`。

### 35.1 邀約與助理代打

婚宴、告別式、運動會、企業活動、廟會、公益募款、開幕剪綵、站台助講。
每一種都可以親自去、派助理去，或推掉。

**每位助理一個月只能跑一場**，效果是親自到場的 0.55 + 能力×0.08。
能力高於忠誠的助理有機率在場上替你答應你沒有答應過的事。

## 36. 社交平台

追蹤數是獨立的數字，跟知名度不是同一件事：
有十萬追蹤但走在路上沒有人認得的政治人物非常多，反過來也有。

| 行動 | 門檻 | 為什麼 |
|---|---|---|
| 開直播 | 氣魄 ≥ 3 | 留言區不會對你客氣 |
| 街頭宣講 | 氣魄 ≥ 4 | 你會站在一個沒有人有義務停下來的地方 |

兩者都可以帶一套組織理論當主軸，理論會顯著拉高表現分。

## 37. 事件的權限門檻

分成兩層：

**選項層級**——政治素人可以對颱風有意見，但「宣布停班停課」那個按鈕是暗的，
旁邊寫著「要有行政首長的權限，這種事情不是喊一喊就會發生」。
被鎖住的選項不會消失，因為看得到那個按鈕是暗的，比看不到有意義得多。

**事件層級**——只有「有人主動來找你」的事件才要求聲望。
純粹的世界新聞素人也看得到，他只是沒有辦法下令而已。
（政治素人仍看得到 55 則事件，門檻沒有把開局鎖死。）

### 37.1 表態反對

每一則事件底下永遠有一個表態反對的選項。這是政治工作最常見也最便宜的回應：
不需要方案，只需要立場。用詞在七種說法之間輪替，效果由口才、氣魄與判斷決定——
同樣一句反對，講得好是立場鮮明，講得差是為反對而反對。

### 37.2 媒體攻擊

機率 = 5% + 知名度×3.5% + 汙名×3.0%，主打形象再乘 1.5 倍。
**退出兩大黨的人會被該黨親近的媒體同時圍剿**，強度乘 2.4，持續十個回合。

五種回應：召開記者會逐條說明、委任律師提告、完全不回應、
反過來質疑對方的金主、透過相熟的記者放另一個版本（要動用人情）。

## 38. 半導體產業

這個產業佔台灣出口超過四成、佔加權指數超過四成，
把它壓成一個 `sectors.semiconductor` 的小數是嚴重的失真。

| 版圖 | 全球市佔 | 技術 | 毛利 | 研發強度 | 對中曝險 |
|---|---|---|---|---|---|
| 晶片製造 | 63% | 4.6 | 53% | 8.2% | 11% |
| 記憶體製造 | 14% | 3.2 | 21% | 6.1% | 26% |
| 電子組件 | 31% | 3.6 | 19% | 4.8% | 44% |
| 晶片設計 | 19% | 4.1 | 38% | 23.5% | 51% |
| 上游設備 | 6% | 2.4 | 24% | 9.4% | 18% |

記憶體的景氣振幅（0.52）是晶圓代工（0.16）的三倍以上，
因為它的價格由全球供需決定而不是由技術決定。

五項結構性風險：人才斷層、供電、用水、出口管制、產能外移。

技術水準決定你在別人的供應鏈裡有沒有辦法被替換掉，市佔只是那件事的結果。
研發強度是唯一一個今天投下去、五年後才看得到的數字，
而政治人物的任期通常比五年短——這句話寫在遊戲介面上。

## 39. 預算的權責分工

**編預算是行政部門的權力，立法院與地方議會只能審。** 這是憲政層級的分工，
所以民代玩家看到的預算頁不會有滑桿。

| 動作 | 幅度上限 | 政治資本 | 說明 |
|---|---|---|---|
| 刪減 | 15% | 8 | 砍掉的錢不會回到別的地方 |
| 凍結 | 30% | 5 | 錢還在但不准動，解凍要行政部門來做專案報告 |
| 附帶決議 | 0 | 3 | 沒有強制力，但寫進紀錄之後很難完全不理 |

凍結才是民代真正的武器，因為報告什麼時候排得進來由你決定。

### 39.1 2027 年度的兩項特別預算

| 項目 | 金額 | 年限 | 政治效果 | 財政效果 |
|---|---|---|---|---|
| 全民現金普發 | 2,360 億 | 1 年 | 滿意度 +6，八回合衰減 | 全數舉債 |
| 零到十八歲每月五千 | 1,980 億 | 4 年 | 滿意度 +4，十六回合衰減 | 舉債，且推高社福的剛性支出 |

政治效果是立即的，財政效果是長期的——順序反過來就是問題所在。

## 40. 埋下的雷：幕僚的來歷

招募幕僚時會顯示一段來歷，讀起來像人物設定：
「家裡的加工廠前兩年收掉了，他沒有多談，只說還有一些事情要處理。」
「用的東西都很好，開的車也不便宜，他說是家裡本來就有一點底子。」

十二種來歷裡有六種帶著 `graftRisk`，每年 5% 的機率收下不該收的錢。
遊戲不會標記出來，這是刻意的。

事發之後有三條路，三條都要付錢：
- **切割**：最快止血，但辦公室裡剩下的人會開始算自己的退路
- **自首並返還**：花錢也丟人，但那些準備寫你的稿子會換方向
- **硬扛**：在法律上沒有錯，在新聞上完全沒有用

## 41. 存檔的量化

五千八百五十個 POP × 二十個維度，照原樣序列化會超過瀏覽器的容量上限。
所以有界的欄位在存檔時量化成一個位元組：

| 欄位 | 型別 | 倍率 | 解析度 |
|---|---|---|---|
| ideology / china / playerFavor | Int8 | 12 | 0.083 |
| support / identity / femaleShare | Uint8 | 250 | 0.004 |
| sol / awareness / militancy / enthusiasm | Uint8 | 50 | 0.02 |

人口與所得保留 Float32，因為它們的範圍不受限。
玩家看到的是四字語詞，這個誤差永遠不會被看見。
存檔因此從 2.03 MB 壓回 1.11 MB。

## 42. 建角記憶與存檔時機

### 42.1 上一局怎麼開，下一局就從那裡開始

建角畫面要填的東西在 v0.5 之後變得很多：姓名、性別、學歷、年齡、起點、
政黨路線、出身、六項屬性、家鄉選區、十三條價值觀軸、兩岸七個維度。
開第二局的人多半只想改一兩個地方，讓他從頭再點一次是沒有道理的。

所以 `localStorage` 裡另外存一份 `p-election:setup`，記的不是一個世界，
只是建角畫面上的那幾個選擇。它跟存檔是分開的兩個鍵——刪存檔不會把它一起刪掉。

### 42.2 讀回來的時候要驗一次

資料檔會改。選區可能被刪、軸可能被改名、出身可能被拿掉。
所以 `loadSetupPrefs()` 的每一項都拿現在的資料檔驗過：

| 項目 | 驗法 | 驗不過 |
|---|---|---|
| 姓名 | 非空字串、截斷到 8 字 | 退回預設值 |
| 起點／出身／路線 | id 要存在於現在的資料檔 | 退回預設／清空 |
| 家鄉選區 | `byId.district` 查得到 | 清空，縣市也一起重設 |
| 年齡 | 夾進該起點的 `ageRange` | 夾到邊界 |
| 屬性 | 只收現在的六項，夾進 0~5 | 該項退回 2 |
| 價值觀／兩岸 | 只收現在的軸與維度，夾進 −5~5 | 該項退回 0 |

整份紀錄解析失敗（例如被別的程式寫壞）就直接當作沒有。
**不能因為一次資料更新就讓玩家的建角畫面壞掉。**

### 42.3 存檔的時機

v0.5.0 之前，自動存檔只在 `reallyEnd()`（結束一個回合）裡發生。
也就是說一個玩家花十分鐘建完角、看完開場、選完黨，
在按下第一次「結束這個月」之前關掉分頁——這一局完全不存在。

現在有兩個新的存檔點：

1. `createGame()` 一回來就存
2. 選完政黨之後再存一次（選黨是開局的一部分，不是第一個回合的行動）

另外自動存檔失敗不再安靜地過去。空間滿了會直接跳訊息說原因——
安靜的失敗會讓玩家以為有存到，直到下一次開啟才發現整局不見。

### 42.4 政黨的選擇不收屬性點

v0.5.1 曾經把政黨路線移進建角流程並收 1~2 點屬性，v0.5.4 整個退回去了。

理由是這件事收了兩次錢。加入大黨的代價本來就寫在遊戲裡：資源多但要排隊，
提名要看黨中央臉色，黨紀投票會逼你在選區民意跟黨團之間選一邊。
那些代價玩家會在往後八年一直付。在建角畫面再扣他兩點屬性，
等於同一個決定被罰兩次，而且第二次的罰則跟那個決定的實際內容沒有關係。

現在屬性成本只看起點與出身（議助 −3、企業二代 −4），
加入哪一個黨回到開局之後的第一個決定。上一局選過的黨仍然會被記住並標示出來。

## 43. 前兩次做一件事

18 個行動，每一個的前兩次都有專屬文本，每次三種變體，共 105 段。

### 43.1 為什麼是兩次

第一次是「我不知道這件事長什麼樣子」：你不知道跑攤要幾點到、不知道記者會該講幾件事、
不知道那個包廂裡為什麼沒有人做紀錄。第二次是「我知道它長什麼樣子了，但我還很笨拙」：
你把皮鞋換成球鞋、把稿子從三頁改成三行、開始知道什麼時候該遞名片什麼時候只要點頭。

這兩種心情只會出現在最前面。第三次之後它就變成工作的一部分了，
再特別講一次反而假。所以不做第三次。

### 43.2 變體由種子決定

三種變體不是用當下的亂數抽的，而是 `hash(種子 + 行動代號 + 第幾次) % 3`。
同一顆種子重開會拿到同一段，這跟這個遊戲的其他隨機一樣：存檔要能重現。
不同種子開新局才會看到不同的版本。

### 43.3 計數的時機

掛在 `CharacterSystem.spendAP()`，也就是行動點真的被扣掉的那一刻。
這一點很重要：deferred 的行動（上節目、開直播、組織理論……）打開選單時不扣點，
所以「打開節目表看一看然後關掉」不會算成做過一次。真的上了才算。

做不成的行動會退回計數（`FirstTimeSystem.refund`）——
形象門檻沒過、民調專戶錢不夠，這些情況都先扣了點再發現做不成，
那一段文本不應該被白白用掉。

事件消耗的行動點不帶 `action`，所以不會被算成任何一個行動。

## 44. 行動點鎖死在兩點

從 v0.5.2 起，每回合固定兩點，不因為職位、團隊、體力或疲勞而變動。

一個縣市長一個月能親自出席的場合，並不會比一個政治素人多。
差別在於他做的每一件事份量比較重，而不是他能做比較多件。
把這個數字鎖死之後，玩家的每一次取捨才是真的取捨——
否則遊戲後期會變成「反正點數夠，全部都做」。

硬撐的空間留在 `maxOverdraft`，那是另一回事：那不是你變得比較有時間，
是你把身體先借出去用，而且有機率在某個晚上突然撐不下去。

連帶調整：常駐通告的上限從 3 個降為 1 個。
兩點的回合被固定行程吃掉一半以上，就沒有什麼好選的了。

## 45. 回合尺度的用字

平時一回合是一個月，選前兩個月切成一週一回合。
介面上每一處講到時間單位的地方都要跟著換：

| 位置 | 月回合 | 週回合 |
|---|---|---|
| 結束回合的按鈕 | 結束這個月／結束十二月，準備跨年 | 結束這一週 |
| 選戰倒數 | — | 結束這一週（投票倒數 N 週） |
| 休息視窗的標題 | 這個月還剩下幾天 | 這一週還剩下幾天 |
| 不休息的按鈕 | 不休息，直接進下個月 | 不休息，直接進下一週 |

週回合的判斷必須放在所有以「月」為單位的說法**前面**，
否則玩家會在只剩三週的時候看到「結束十二月，準備跨年」。

按鈕上刻意不提「還有幾件事沒處理」。待決事項就列在畫面最上方，
在按鈕上再念一次只會讓人覺得被催促——那不是這個遊戲想給的感覺。

## 46. 男女差距怎麼寫

原本的寫法是把兩個數字並排：

```
進盟    男 38.7    女 41.1    −2.4
```

問題是玩家真正想知道的那件事——哪一邊比較挺、差多少——要自己在腦子裡算，
而且負號代表什麼還要先想一下。改成：

```
進盟    女+2.4                 男 38.7  女 41.1
國民    男+3.2                 男 37.4  女 34.2
民生    幾無差異                男 15.8  女 15.7
```

方向直接寫在最顯眼的位置，男女各用一個顏色，原始的百分比縮小留在右邊。
差距小於 0.3 個百分點寫「幾無差異」，因為那個大小的差在民調誤差裡看不出來，
硬給一個方向反而是在誤導。

寫法收在 `format.genderLean()`，資料頁與中華民意基金的交叉表共用同一個函式——
同一件事在兩個地方用兩種寫法，是很容易發生也很沒有必要的事。

## 47. 民調的招牌題組

九家民調公司各有自己的切法。切法本身就是一種立場：

| 公司 | 題組 | 這代表他們相信什麼 |
|---|---|---|
| 燦爛島 | 九大族群交叉表 | 社會可以被切成九塊，而且那九塊各自有自己的邏輯 |
| 蓋皮尤 | 議題關注度排序 | 議題順序比支持度更能預測選舉 |
| 政智選研 | 國家認同 + 兩岸七維 + 理由 | 這一題做了三十年，長期資料比單次數字重要 |
| 中華民意 | 性別年齡交叉 | 年輕男女的立場正在分開，這是新的主軸 |
| 山海 | 六都與非六都 | 全國平均是一個沒有意義的數字 |
| 聯日報 | 一對一對決 | 選舉最後都會變成兩個人的事 |
| 明淨 | 逐月趨勢 | 賣的是變化量而不是絕對值 |
| 匯流 | 單題快問快答 | 速度就是價值 |
| PTC | 網路開放自填 | 樣本夠大就好——附一段警語說明為什麼不是 |

這些數字從 v0.5.0 就算出來了，但民調視窗一直沒有把它們畫出來。
v0.5.3 全部接上，另外加上十八位部會首長的滿意度（前五名與最後三名）。

政智選研每六個回合才發布一次，實機測試不一定碰得到，
所以九種題組的欄位完整性改由測試逐一產生驗證，而不是靠人去點。

## 48. 初選落敗之後的三條路

沒拿到提名的那一頁有三個選項：

| 選項 | 意思 |
|---|---|
| 接受結果，留下來輔選 | 這一次算了，人情留著下一次用 |
| 脫黨參選 | 拿回自主權，代價是兩大黨親近的媒體會同時圍剿你十個回合 |
| **心灰意冷** | 就到這裡 |

第三條走的是跟行動選單裡「退出政壇」同一套結算與事後談，
但開場的講法不一樣。行動選單那一條是想清楚了才走：
你把鑰匙放在桌上，把牆上的合照一張一張拆下來。
這一條是在開票那個晚上決定的：

> 開票結束之後，服務處的人陸續走光了，只剩下最早跟著你的那兩三個還在收椅子。
> 你想起這幾年缺席的那些婚禮、那些沒有接的電話、那些講到一半就被打斷的話。

真的離開政治的人，多半是後面這一種。所以這條路要存在。

技術上要注意一件事：退出時必須把該年度的 `elecDone_` 旗標一起設起來，
否則玩家看完結算之後，排程還會再偵測到同一場選舉——
跟 v0.5.2 修掉的那個 bug 是同一個成因。

## 49. 沒有立場的人，事後談要怎麼寫

`epilogue()` 原本挑三條玩家立場最鮮明的軸來講，
條件是絕對值 ≥ 1。問題是有一種玩家把十三條軸全部留在 0——
他不是忘了設，他就是沒有意見。這種人拿到的事後談是空的。

補法不是替他編出立場來，那會讓整套結局系統的前提垮掉。
改成講這個國家在他不表態的那些年裡自己走到哪裡去了：
挑國家價值觀移動最多的三條軸，照它們實際走的方向敘述，
每一段標明「你從來沒有表示過意見」。

遺憾那一句也換掉。有立場的人拿到的是：

> 他偶爾會在電視上看到這些新聞。年輕的時候他相信的不是這樣，但他已經沒有位子可以說話了。

沒有立場的人拿到的是：

> 他偶爾會在電視上看到這些新聞，然後轉台。
> 這些事情往哪個方向走，他年輕的時候就沒有想過，現在更沒有理由開始想。

後面那一句比前面那一句難受，而且它應該難受。

## 50. 兩段文字擺在一起的時候

結果視窗上半是「前兩次做這件事」的專屬敘述，下半是這一次實際發生的場景。
兩段分別寫的時候都沒問題，擺在一起就會打臉：

> **選區跑攤・第一次**
> 第一次自己出門跑攤……沒有人認得你。
>
> 賣魚的老闆娘一看到你就把手在圍裙上擦乾，
> 她拉開嗓門跟整排攤販說**這個少年仔上次真的有來**幫忙處理排水溝。

這不是文字寫壞了，是兩個系統各自成立卻沒有人負責它們的交集。
處理的方式不是把好句子刪掉，是讓它們在對的時候才出現。

### 50.1 三個來源

| 來源 | 例子 | 處理 |
|---|---|---|
| 場景分支假設你來過 | 「上次真的有來幫忙」 | 標 `assumesHistory`，前兩次不抽 |
| 第一次敘述綁定場合 | 「走到市場的時候」 | 改寫成不綁場合——底下可能是告別式 |
| 回報的感覺句假設你來過 | 「還說上次的事情謝謝你」 | 改寫，並在前兩次壓住熱度上限 |

### 50.2 門檻要跟著資料走

`assumesHistory` 的生效範圍不是寫死的 2，而是讀 `firstTimes.occurrences`。
哪天把專屬敘述從兩次改成三次，這一邊會自己跟上——
兩個常數各自維護，遲早會有一個被改到而另一個沒有。

### 50.3 同一類問題的另一半

素人也不該拿到假設他有服務處或民代身分的段落。
`requires: 'office'` 要已經掛牌的服務處，`requires: 'member'` 要議員或立委的身分。
沒有服務處的人留不下服務處的電話，不是民代的人也沒有議事堂可以站上去。

這跟事件的選項門檻（第 37 章）是同一個原則，只是那邊擋的是**你做不到的事**，
這邊擋的是**不可能發生在你身上的敘述**。

### 50.4 讓資料層自己擋

三道檢查寫進 `validate-data.js`：

- 文字裡出現「上次」「認出你」卻沒有標 `assumesHistory` → 建置失敗
- 出現「服務處」「議事堂」卻沒有上身分門檻 → 建置失敗
- 跑攤的第一次敘述出現「市場」「早市」「攤商」 → 建置失敗

以後新增場景的時候，忘記標記會在寫完的當下就被擋住，
而不是等玩家在畫面上看到兩段互相打臉才發現。
